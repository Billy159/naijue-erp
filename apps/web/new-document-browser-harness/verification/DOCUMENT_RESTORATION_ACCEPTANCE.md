2. 在已授权 Mac 环境加载新产物 `dist/synthetic-new-transfer.html` / `synthetic-new-sale.html`，确认不是旧4daa缓存。

## 第二轮最小修复与显式回归命令

Mac 首轮实机仍发现两项差异：列表筛选旁空白块、销货候选 Esc 后焦点未返回触发按钮。第二轮不是全站“通过”，两项仍须在更新后重验。

- 空白块的可复现 CSS 根因：`AuthenticationPanel` 包裹业务应用，而原 `.auth-panel button` 将 token 的12×16移除按钮强加为 `min-height:34px;padding:6px 14px;border:1px;background:white`。现在认证 CSS 只作用自有 form/session/actions/cancel/password-dialog，不再覆盖业务子树。**没有隐藏或删除合法搜索 input**；正式认证 JS/授权协议未改。
- 销货候选打开前显式保存真实触发按钮，避免 React 自动聚焦弹窗搜索框后才记录焦点；Esc 后回到原触发按钮。不改候选选择/保存语义。

在接收第二轮 overlay 后，除了原构建命令，显式执行以下命令（不需要修改 package.json）：

```sh
node apps/web/src/authentication/tests/run-style-isolation-tests.mjs
node apps/web/src/authentication/tests/run-dom-tests.mjs
node apps/web/src/current-form/tests/run-sales-create-route-dom-tests.mjs
```

证据边界：样式隔离测试编译实际 `authentication.css` 与共享 controls CSS，在两种加载顺序下用 JSDOM 断言业务 token 宽12/高16/padding0/无边框/透明、认证按钮34px和认证输入38px仍保留，并验证查询/文字操作/业务警告不受认证样式污染。认证7组 DOM 及销货 Esc 精确回焦点断言已在云环境终态通过；这些不是浏览器像素证据。
