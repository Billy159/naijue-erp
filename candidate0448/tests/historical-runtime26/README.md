This is **test-source routing**, not legacy production compatibility, a migration,
or authority to run an old target. It does not change old source pins, WeakSet
brands, original test assertions, engines, current metadata, or business permissions.

## Why separate it

The original40-source oracle requires fingerprint726d… and original native source
C41. Unified e6 intentionally has successor native source87f3…. Original test
leaves imported their local loader, so setting NAIJUE_SOURCE_COHORT_ROOT alone did
nothing. Explicit RED at e6 was18 registered tests:15PASS/3FAIL (the schema leaf
failed at top-level before its individual tests registered). Suppressing that error
or repinning726d would falsely approve new bytes as the old oracle.

## What actually executes

`original-oracle.test.mjs` imports the two original complete test leaves unchanged.
Their native lifecycle children are EventEmitter mocks; read manifest uses only
scripted query results. The only original real child invocations are Node running
the fixed schema engine with `--help`, noargs and `--approve`, all refusing/returning
before engine work. Wrong finite target likewise refuses before binary/port access.
The helper additionally runs Node's existing dependency verification script.

Root test wiring replaces the two old local-oracle paths with these named wrappers.
It retains all other entries, including current successor tests through tests/*.test.ts.
`npm run test:historical-runtime26` explicitly combines wrappers/integrity negatives
with `tests/native-runtime26-sequence-system-acl-successor.test.ts` and the14
new unified-install source/dispatch tests.
The helper separately requires active native source87f3…, and rejects the C41 fixture
as an active successor. Historical PASS cannot replace current successor validation.

The new `unified-new-target-install.test.ts` also uses this explicit portable oracle
when UNIFIED_INSTALL_SOURCE_ROOT is absent and closes it in an after hook. A supplied
external source root is still checked normally; a bad/empty value does not silently
fall back. This adaptation changes **only the test leaf**. The nine frozen installer
source/documentation files and their production sourceRoot contract remain identical.
Its original missing-environment failure was reproduced before the adaptation.

## Verification boundary

Use exact Node24.21.0, with NODE_PATH/NODE_OPTIONS/NODE_PG_FORCE_NATIVE unset.
No retained-R directory or NAIJUE_SOURCE_COHORT_ROOT environment is needed.
New negatives reject mutated fixture bytes, unknown paths, missing source before
tree creation, getters, fake oracle tokens, and historical bytes offered as active
successor. No skip, assertion weakening or old engine modification is used.

The focused source tests do not approve a PG target, full root gate, performance,
release-helper approval pins, payment Git-ancestor environment, or production.
