## 对齐基准

- 32px 单行控件；正常态浅灰底，焦点态单圈品牌蓝边框。
- 已选款号使用白色中性 Tag，可点击复制；多款时折叠为中文“更多”。
- 商品候选在左、资料与图片在右；候选列表与输入框等宽，资料卡右边与“全部仓库”控件右边对齐，窄视口按可用宽度收缩。
- 最近搜索标题和历史项均用 13px 常规字重，与“全部仓库”选项一致；候选列表用“商品款号 / 商品名称”列标题区分字段，款号使用常规字重、名称使用次级文字色。
- 只将已确认选中的商品作为查询条件；临时搜索词不进入库存查询。
- 候选、历史、键盘选择与预览继续由现有 Arco Select 承担。
- 商品搜索资料预览不显示年份；其他既有商品资料继续展示。
