最终五层：页面身份与导出/刷新/更多 → 常用查询及可展开附加条件 → 已执行范围/汇总/表格动作 → 商品分组矩阵 → 基础行分页。

这种任务区、表格工具区分离借鉴 [SAP List Report](https://www.sap.com/design-system/fiori-design-web/v1-96/discover/frameworks/sap-fiori-elements/list-report/list-report-header-sap-fiori-elements) 与 [Carbon Data Table](https://carbondesignsystem.com/components/data-table/usage/)；分页依据基础记录，参考 [Carbon Pagination](https://carbondesignsystem.com/components/pagination/usage/) 与 [AG Grid Row Pagination](https://www.ag-grid.com/javascript-data-grid/row-pagination/)；固定识别列参考 [Ant Design Table](https://ant.design/components/table/)。仅借鉴行为，未引入这些框架。
