## 可复用经验与边界

- 原文件的打印日期不能替代业务结账时点；Demo 授权可先固定测试数量期初，正式上线另确认完整全仓库存和截止时点。
- 切到库存快照时，历史源流水和已有运行增量都须由期初承接，不能再重复加一次；保留原数据，以检查点和期初基数读取实现。
- 历史尺码映射与当前尺码目录须共用一套显示规则；女装不能沿用男装身高 / 字母对应关系。原 SKU 身份、历史名称编码和条码绑定作为独立来源保留。
- 混合单位库存逐单位汇总，不能把件、条、双、套、张、次等相加后称为“件”。
- 原生浏览器的活动窗口可能被用户或其他任务切换。截图和页面文本必须在同一次观察中核验目标 URL 与实际内容后保存，不能把一次观察的文本与随后另一窗口截图混作证据。
- 旧服务验证脚本假定匿名演示会话；同期员工账号模块改成正常登录后，该脚本的旧登录步骤不再适用，本次未将该脚本列为通过证据。数据核验及已登录页面核验分别有独立证据。
- 共享工作区保留其他任务的账号、界面等修改。本次没有整理整库 Git 提交，也没有以其他模块变化扩大数据清洗范围。
