## 保存和读取

- 新建提交 `seasonIds: UUID[]`，可以明确传空集合，不能缺字段或传 NULL。编辑可保留原来的 NULL；已知选择不能改写为“未知”。清空必须明确传 `[]`。
- 保存一维、无重复、无 NULL 元素的真实字典 ID 集合。非法或不存在的 ID 整次拒绝，不静默去重或丢弃。
- 商品季节与其他商品字段共用一次版本核对、事务、原始审计和请求回执；失败整次回滚。同样的选择不单独产生新版本或假改动。
- 列表仍显示既有季节文字；编辑接口额外保留 NULL 与空集合的区别。名称按字典顺序显示。原来的单值编辑接口在新合同启用后明确拒绝旧式写入，避免覆盖多选。
- 季节筛选按“命中所选任意一季”筛选；与其他筛选条件同时生效。同一商品只计一次，库存不因多个季节而重复累计。

## 数据约束和引用保护

数组元素不能直接使用普通单列外键，因此新增列的同时实施以下保护，不能只靠页面检查：

1. 数据库检查数组形状、重复和空元素。
2. 商品保存时在同一事务内，按固定顺序核实并锁定被选中的季节字典记录；不存在则拒绝。
3. 季节 ID 仍被任何保留商品引用时，拒绝删除或改 ID；原单值外键也继续生效。
4. 用真实数据库的并发负例确认“新增关联与删除字典”不能留下无效引用。未经实际列、约束、权限和转换结果核验，后端不启用新写合同。

季节字典的现有维护权限不扩大，不因本改动新增字典增删菜单。
