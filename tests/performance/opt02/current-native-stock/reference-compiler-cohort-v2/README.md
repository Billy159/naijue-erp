## Exact mechanical changes

`universe.mjs` is the frozen v1 compiler with exactly one import changed to
`./source-cohort.mjs`; `render.mjs` is byte-identical to the old renderer. Thus
new policy and renderer use one new private policy WeakSet. The source wrapper
accepts an explicit primitive portable root and checks the frozen relative
200-file byte closure before importing code and after loading a plan. The anchor
contains17 runtime-value source modules,14 pg dependency package trees and44
explicit source inventory files; the source manifest records their hashes.
Type-only imports are not executed. No machine-specific source root is embedded.

`loadPairedSourcePlan({sourceRoot})` imports the original source-plan/v22/observer
from that same verified root. It calls the original real `loadPlan`,
`assertPlan` and `assertSources`; only those genuine results are mapped. Later
compiler checks call that same original private WeakSet, and source reads route
to that same original module. Copied plans/files or self-labelled approvals are
rejected. There is no cast, fake assert, rewritten old loader, temporary active
rollback, or database-derived expected value.

The anchor is independently retained C12 source provenance, not a signature of
metadata review or a defense against privileged host tampering. A future host
must separately freeze the paired root identity/closure, active successor/SQL,
physical fresh target and canonical expected-before-target review. The original
v22 target/131/body/definition/ACL predicates remain unchanged.
